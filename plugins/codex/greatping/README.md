# GreatPing for Codex

Phone alerts when Codex finishes a turn, with explicit GreatPing MCP tools.

This preview plugin requires an installed GreatPing CLI >=0.4.0 and <1.0.0,
and Node.js >=22.20.0 available to the host. It does not download a runtime or
pair your computer. Run `greatping login` yourself if pairing is needed.

Use `greatping setup codex` and `greatping doctor`.
For an explicit launcher, run from this directory in your terminal:

```sh
node scripts/bridge.mjs codex configure
node scripts/bridge.mjs codex check
```

Configure once; the launcher is stored outside the plugin cache and survives
plugin updates. Completion alerts are on by default; pass `--no-finished` to configure to disable them. Review and trust hooks in `/hooks`; installing a plugin does not grant trust. Native permissions and questions are not automatically covered.

If CLI integrations already exist, migrate them through their installer.
Plugin hooks stand by while legacy CLI hooks are installed, and plugin MCP
refuses to start beside a separately registered `greatping` server.

See [installation, migration and removal](https://github.com/nobottomline/greatping/blob/main/plugins/README.md)
for exact commands, stable launchers, coverage and verification limits.
